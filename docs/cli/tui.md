# `dainel tui`

Open the terminal UI connected to the Gateway.

Related:
- TUI guide: [TUI](/tui)

## Examples

```bash
dainel tui
dainel tui --url ws://127.0.0.1:18789 --token <token>
dainel tui --session main --deliver
```
