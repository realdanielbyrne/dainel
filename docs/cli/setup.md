# `dainel setup`

Initialize `~/.dainel/dainel.json` and the agent workspace.

Related:
- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
dainel setup
dainel setup --workspace ~/clawd
```

To run the wizard via setup:

```bash
dainel setup --wizard
```
